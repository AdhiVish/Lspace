# LSPACE Interiors

Scroll-driven website for LSPACE Interiors, built with React, TypeScript, Vite, Tailwind CSS v4, motion and Lenis.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

- All copy, room data and media paths live in `src/data/site.ts`.
- Images and videos are in `public/media/`.
- Real project photos for each floor-plan room go in `PROJECTS` in `src/data/site.ts`.
